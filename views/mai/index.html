概览

绑定和测试

先在这里测试一组凭据能不能登录（结果只显示在本页，不会发到 QQ）；勾选「保存」并填 QQ 号，就等于替这个 QQ 绑定好了（视为已同意声明）。国际服推荐 clal；SEGA ID + 密码可以在 clal 过期时自动续登。日服只能用 SEGA ID。

曲库和版本

  
曲库每天定时从 DXRating 刷新（启动时也刷新一次）。「当前版本」默认自动判断：取该区可玩、且收录 ≥10 首的最新版本。从 CiRCLE 起，新曲 B15 = 当前版本 + 上一个版本。版本更新后自动判断没跟上的话，可以在这里手动指定。

  

  
  






  
B50 主题

  
素材放在本机 plugin_data/astrbot_plugin_otoge_prober/mai/themes/，不随插件分发（游戏素材版权属于 SEGA，请自己准备）。背景和 logo 按版本放（default 对所有版本生效）；图标会替换自绘的评级 / FC / FS 徽章。曲绘优先用本机的 jackets_hdd/（如果有），没有的再从 DXRating 下载。上传或删除后会自动刷新预览。
批量上传图标 / 版本 logo（有命名规则和缺失清单）请用总览页的「素材」板块。
