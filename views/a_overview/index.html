指令怎么读

指令 = /游戏 动作 [区服]，例如 /mai b50 日服。区服写在最后，不写就查该用户上一次查的那个服。独立指令（/谱面、/猜歌、/网页绑定、/传分、/传、/批量传、/查分 …）不用加游戏。打错、没空格也认（/舞萌b50）。

传分网站（SDVX / 音击官服）

官服的成绩网站不开会员看不到成绩，所以 SDVX 和音击官服是玩家自己传分：QQ 里 /传分 拿登录链接（30 天免登录；群里发的链接点开后要本人回 /传分 确认 码 才登录），或 /传、/批量传 直接在聊天里传；网页绑定页上选 SDVX / 音击官服也能直接进。网站和网页绑定是同一个服务、同一个公网地址（路径 /scores）。曲库 SDVX 来自 Tachi、音击来自 otoge-db，每天自动更新；曲绘从 sdvx.in 拿，缩成小图缓存在本机。
音击官服开了 オンゲキ-NET Standard（330 円/月）的人可以在网页绑定填 SEGA ID + 密码，之后 /geki b50 自动先同步（/geki 同步 手动拉，5 分钟冷却），密码加密存在 geki_official/。这个自动查还没用真账号测过，出问题的话日志里搜 geki official。SDVX 开了 e-amusement 会员的可以在「批量传分」直接选官网导出的 CSV。

传过分的人

成绩存在插件数据目录 scorebook/users/<QQ>.json，每人一个文件。「踢下线」= 让这个人在所有设备上的传分网站登录失效（他自己发 /传分 登出 也一样）。

小游戏

群里 /猜歌（开字母）、/猜曲绘、/猜谱面；一个群同时一局，没人说话会自动结束（开字母 20 分钟、曲绘 / 谱面 8 分钟）。这里能看现在哪些群在玩、强制结束一局（局面只在内存里，重载插件也会清掉）。

小游戏总开关

在这里切马上生效，不重载插件；关掉会把正在玩的局一起结束。每个群「热闹时邀请小游戏」在下面「自然语言开关」那张表里。

别名收集（猜歌投票）

群里猜歌时有人用原名猜中，我会让大模型从这一局没猜中的消息里挑像外号的，在群里投票（回 y / n）。这里改的设置马上生效，不会重载插件，正在玩的猜歌局不受影响。

群友 3 分钟内回「别名 外号」（几首时「别名 序号 外号」）就发起投票；只认这个开头，别的聊天不会被当成外号。和原名、已有外号、别的歌的外号重了会直接说明，不发起。

自然语言开关 · 热闹时邀请小游戏

自然语言：这个群里 @机器人 说「帮我查一下中二 b30」之类的话，先过关键词粗筛，命中才调用大模型判断意图（每次一个短请求）；没打开的群完全不调用。
热闹时邀请：群里聊得热闹、又没人在玩的时候，轻轻问一句「要不要来一局猜歌？发 /猜歌 舞萌 就开」；群里在聊哪个音游就推荐哪个。全在本地判断，不花 token，不 @ 人。两个开关都是每个群单独开，默认都关。
